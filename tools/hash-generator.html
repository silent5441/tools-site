Generate MD5, SHA-1, and SHA-256 hashes from any text input.

Approximation only — not cryptographically accurate. Use a dedicated MD5 library for security-sensitive work.

What is Hashing?

A hash function maps data to a fixed-size string. SHA-1 and SHA-256 are cryptographic hashes used for integrity verification. MD5 is shown as an approximation only — it has known vulnerabilities and is not provided via the Web Crypto API.
